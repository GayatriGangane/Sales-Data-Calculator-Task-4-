# Sales Data Calculator

## Veda Technology – AI & ML Track

### Day 4 Task – Sales Data Calculator

## 📌 Project Overview

The Sales Data Calculator is a beginner-level Python project developed as part of the Veda Technology AI & ML internship task.

The project analyzes a collection of sales values and calculates basic statistical information such as total sales, average sales, highest sale, and lowest sale.

The project demonstrates the use of Python's built-in numerical functions and basic data analysis techniques.

---

## 🎯 Objective

The main objective of this project is to understand basic numerical data analysis using Python.

The project focuses on:

- Creating a collection of sales values
- Calculating total sales
- Calculating average sales
- Finding the highest sale
- Finding the lowest sale
- Displaying meaningful analysis results
